La APK Android es para detección anti-cheat en MÓVIL: revisa archivos del
propio dispositivo y hacks pensados para móvil, NO el ecosistema PC. El
contrato API con el backend es el mismo que Windows/Linux (POST /api/scans
+ POST /api/scans/<id>/results) — solo cambian las fuentes de evidencia.

Ámbito de detección Android (qué cubre):
  • Minecraft Bedrock Edition (com.mojang.minecraftpe) — el target principal:
    cheats nativos como Toolbox, Horion, Latite Client, Husky, Prestige,
    Catalysm, Rebellion, Exodus, Moon, Flare HCF, Zephyr, ProHvH.
  • Minecraft Java Edition vía PojavLauncher (net.kdt.pojavlaunch y
    net.kdt.pojavlauncher) — corre el JAR original de Mojang en Android +
    permite cargar mods/clientes Java (Vape, Liquid, Wurst, Sigma, etc.).
  • Boardwalk Beta y Boardwalk-merge (variantes de Pojav).
  • Otros launchers Bedrock-mod: BlockLauncher, MCPELauncher, MCPE Master
    (com.mcpemaster.mcpe), Toolbox como launcher (com.tbox.box).
  • Launchers Java alternativos en Android: HMCL (org.jackhuang.hmcl),
    XMCL móvil, Lithium Launch.
  • Game Guardian (com.MGGS y forks) — memory editor #1 en móvil, usado
    para cheatear stats en Bedrock incluso sin cliente custom.
  • Magisk + módulos invasivos, LSPosed/Xposed, VirtualXposed, Lucky
    Patcher, Parallel Space (multi-instance abuse).

Restricciones honestas (qué NO cubre vs Windows/Linux):
  • Sin acceso a /proc/maps de OTROS procesos (Android sandbox post-API 24).
  • Sin USN Journal real — solo FileObserver runtime durante el scan.
  • Sin Prefetch/Amcache — pero hay UsageStatsManager (≈similar valor).
  • Storage Access Framework (SAF) post-Android 11: lectura de /sdcard
    requiere MANAGE_EXTERNAL_STORAGE o Scoped Storage limitado.
  • No leemos los archivos privados de OTRA app (com.mojang.minecraftpe
    /data/data/...) — sí su carpeta pública en /sdcard/Android/data/.
