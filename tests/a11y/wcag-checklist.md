# WCAG 2.1 AA Checklist (manual)

- Estructura semántica: `h1` único por página.
- Contraste mínimo de texto (4.5:1 normal, 3:1 grande).
- Navegación completa con teclado.
- Focus visible en componentes interactivos.
- Labels explícitos en formularios y botones.
- Texto alternativo en imágenes informativas.
- Roles ARIA solo cuando sea necesario.
- Mensajes de error claros y asociados al campo.
