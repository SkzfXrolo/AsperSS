1
Descarga el argus-linux.tar.gz y extraelo: tar -xzf argus-linux.tar.gz && cd argus_linux
2

3
Lanzá el scanner como usuario normal (NO sudo): chmod +x run-argus.sh && ./run-argus.sh TU_TOKEN
4
Para captura de pantalla, instalá UNA tool según tu setup: grim (Wayland wlroots) · gnome-screenshot · spectacle (KDE) · scrot (X11) · imagemagick Si no tenés ninguna, podés saltarla con --no-screenshot.
5
Ver paridad técnica honesta vs Windows en el README incluido en el paquete.
