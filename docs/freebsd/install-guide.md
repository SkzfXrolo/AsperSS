# Instalacion FreeBSD/OpenBSD/NetBSD

1. Instalar Python y toolchain base.
2. Compilar o usar binario compatible.
3. Registrar servicio con `rc.d` (FreeBSD) o equivalente.

## Caveats

- `psutil` puede requerir flags o versiones específicas.
- No aplica registry de Windows.
- Recomendado modo adaptativo del scanner para BSD.
