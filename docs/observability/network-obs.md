# Network Observability (Pack48-G)

## Métricas

- TCP retransmit rate
- packet loss
- RTT p50/p95
- HTTP error rate por status
- pool de conexiones (uso/saturación)
- DNS lookup latency
- SSL handshake latency

## Alertas sugeridas

- packet loss > 2%
- retransmits anómalos sostenidos
- SSL handshake p95 fuera de baseline
