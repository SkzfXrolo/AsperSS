# Sustainability Metrics (Pack48-G)

## Métricas propuestas

- `sustainability.gco2_per_request`
- `sustainability.gco2_per_scan`
- `sustainability.gco2_per_oracle_eval`
- `sustainability.energy_kwh_per_day`

## Baseline y target

- Baseline mensual inicial (mes 0).
- Objetivo: reducción **10% YoY** en intensidad de carbono por operación.

## Reporte

- Dashboard mensual con:
  - tendencia gCO2/op,
  - contribución por servicio (web, scanner, plugin, AI),
  - alertas por regresión (>15% mes contra mes).
