# Chaos Engineering (Pack48-G)

## Principios

1. Hipótesis clara.
2. Experimento controlado.
3. Observación de impacto.
4. Aprendizaje y acciones.

## Herramientas

- Litmus
- Chaos Mesh
- Gremlin
- Chaos Monkey

## Experimentos Argus

- caída de DB temporal
- inyección de latencia API
- failover regional
- presión de memoria

## Frecuencia

- drills mensuales en staging.
- trimestral en ventanas controladas de prod (si madurez lo permite).
