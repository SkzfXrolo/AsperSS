# OpenTelemetry Adoption (Pack48-G)

## Por qué OTel

- Vendor-neutral.
- Unifica traces, metrics y logs.

## Pasos de adopción

1. Instalar SDK + instrumentación automática.
2. Propagar contexto W3C.
3. Desplegar OTel Collector.
4. Exportar a backend elegido.

## Auto-instrumentación

- HTTP client/server
- DB drivers
- colas/tasks workers

## Migración

- Fase 1: traces
- Fase 2: metrics
- Fase 3: logs correlados
