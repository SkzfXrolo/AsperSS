# Guia de instalacion macOS

## Opcion 1: Homebrew (recomendada)

1. `brew tap TBD/argus`
2. `brew install argus-scanner`
3. Ejecutar `ArgusScanner`.

## Opcion 2: DMG directo

1. Descargar `ArgusScanner.dmg`.
2. Arrastrar a `Applications`.
3. Abrir desde Finder.

## Gatekeeper

Si macOS bloquea la app:

- Ir a `System Settings > Privacy & Security`.
- Permitir la ejecucion de Argus.
- Reintentar apertura.
