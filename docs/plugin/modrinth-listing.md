# Draft listing para Modrinth

## Project summary
Argus Anti-Cheat detecta patrones sospechosos en combate, movimiento e interacciones de red para ayudar a staff teams a actuar con evidencia y menos falsos positivos.

## Highlights

- Hybrid checks (Bukkit events + PacketEvents packet layer).
- Observer mode for safe staged deployments.
- Violation pipeline connected to AI Oracle backend.
- Designed for medium/large networks.

## Supported loaders/platforms

- Platform: Bukkit/Paper ecosystem.
- Modrinth category sugerida: `moderation` / `administration`.

## Quick start

1. Download latest `argus-mc-*.jar`.
2. Put file into server `plugins/`.
3. Restart server.
4. Configure `config.yml` and test with `/argus test`.
