# Instrucciones de descarga del plugin

Ruta prevista para la web: `/descargar/plugin` (actualizacion documental, sin cambios de backend en este sprint).

## Flujo recomendado para usuarios

1. Ir a la pagina de descarga del sitio Argus.
2. Hacer click en **Descargar plugin**.
3. Guardar `argus-mc-<version>.jar`.
4. Copiar el archivo en la carpeta `plugins/` del servidor.
5. Reiniciar o ejecutar reload completo del servidor.

## Notas de publicacion

- El enlace deberia apuntar al release/tag mas reciente del plugin.
- Mantener visible la compatibilidad de versiones Minecraft.
- Agregar hash SHA256 en la pagina de descarga cuando el owner lo confirme.
