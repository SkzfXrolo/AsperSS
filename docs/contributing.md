# Contributing

## Flujo recomendado

1. Crear rama desde `main`.
2. Hacer cambios pequenos y atomicos.
3. Ejecutar checks locales relevantes.
4. Abrir PR con contexto tecnico y plan de prueba.

## Convenciones

- Commits claros y orientados a impacto.
- Mantener separacion por componentes (`web_app`, `source`, `minecraft_plugin`, `scripts`, `docs`).
- No subir secretos ni tokens.

## Checklist minima de PR

- [ ] Build/CI en verde.
- [ ] Documentacion actualizada.
- [ ] Riesgos y rollback descritos.
