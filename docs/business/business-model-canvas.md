# Business Model Canvas

- **Key Partners:** hosting providers, marketplaces, communities, integradores.
- **Key Activities:** I+D anti-cheat, soporte, operaciones cloud, ventas B2B.
- **Key Resources:** datos de señales, equipo técnico, marca, infraestructura.
- **Value Proposition:** detección accionable con menor falso positivo y rollout seguro.
- **Customer Relationships:** autoservicio + CSM para enterprise.
- **Channels:** web, comunidades gaming, partnerships, marketplace plugins.
- **Customer Segments:** owners de servidores, redes grandes, equipos seguridad.
- **Cost Structure:** ingeniería, cloud, soporte, marketing.
- **Revenue Streams:** suscripción Pro/Enterprise, servicios, partnerships.
