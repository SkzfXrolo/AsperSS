# Red Team Manual

Marco recomendado: **PTES** + referencias NIST SP 800-115.

## Fases

1. reconnaissance
2. scanning
3. enumeration
4. exploitation
5. post-exploitation
6. reporting

## Toolkit base

- Nmap
- Burp Suite
- Metasploit
- BloodHound
- Mimikatz
- CrackMapExec

## ROE template (mínimo)

- alcance autorizado
- ventanas horarias
- activos fuera de scope
- canales de escalamiento
- criterios de parada

## Reporting template

- resumen ejecutivo
- cadena de ataque
- impacto de negocio
- evidencia
- recomendaciones priorizadas
