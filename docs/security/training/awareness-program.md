# Security Awareness Program

## Curriculum mensual

1. phishing awareness,
2. higiene de contraseñas + MFA,
3. ingeniería social,
4. OWASP Top 10 aplicado a Argus,
5. reporte temprano de incidentes.

## Simulación de phishing

- herramientas: KnowBe4 o GoPhish self-hosted,
- frecuencia: mensual,
- campañas temáticas por rol.

## Métricas

- click rate,
- report rate,
- completion rate de training,
- tiempo de reporte de correo sospechoso.
