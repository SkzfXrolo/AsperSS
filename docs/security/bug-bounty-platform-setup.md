# Bug Bounty Platform Setup

## Comparativa breve

- **HackerOne:** ecosistema amplio, costo alto.
- **Bugcrowd:** buen triage gestionado.
- **YesWeHack:** fuerte en Europa.
- **Self-hosted (BugBounty.js):** control alto, overhead operativo mayor.

## Setup checklist

1. definir in-scope/OOS,
2. tabla de recompensas por severidad,
3. SLA de respuesta (acuse/triage/remediación),
4. flujo de escalamiento y comunicación,
5. política de disclosure coordinado.

## SLA sugerido

- acuse: 72h
- triage: 7 días
- actualización de estado: semanal hasta cierre.
