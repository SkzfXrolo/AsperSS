# Incident Command System (ICS)

Roles: Incident Commander, Liaison, Comms, Tech Lead, Scribe.

Severidad:

- SEV1: crítico, all-hands.
- SEV2: alto impacto.
- SEV3: moderado.
- SEV4: menor.

Canales:

- war room dedicado
- status page
- comunicación a clientes

Post-incidente: postmortem blameless con acciones y dueños.
