# Security KPIs Dashboard

## KPIs operativos

- MTTD (mean time to detect)
- MTTR (mean time to resolve)
- patch SLA compliance %
- vuln backlog (critical/high/medium)
- training completion %
- phishing click/report rate

## Metas 2026

## Q1

- MTTD < 24h
- critical patch SLA >= 80%

## Q2

- MTTR < 7 días para High
- training completion >= 90%

## Q3

- vuln backlog critical = 0 sostenido
- phishing report rate >= 40%

## Q4

- patch SLA compliance >= 95%
- tabletop exercises trimestrales completados

## Visualización (Grafana)

- panel 1: incidentes (MTTD/MTTR),
- panel 2: vulnerabilidades por severidad/edad,
- panel 3: compliance/training,
- panel 4: abuse defense (rate-limit blocks, bot score).
