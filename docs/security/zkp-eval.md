# Zero-Knowledge Proofs Evaluation

Tecnologías: zk-SNARKs, zk-STARKs, Bulletproofs.

Use case potencial Argus:

- demostrar cumplimiento/no-cheat sin exponer telemetría completa.
- agregación privada entre servidores.

Limitaciones actuales:

- costo técnico y criptográfico alto.
- complejidad de producto.

Recomendación: proyecto de investigación, no implementación inmediata.
