# Vendor Risk Management

## Vendors actuales (ejemplo base)

- Render (hosting),
- GitHub (SCM/CI),
- Cloudflare (si se usa para edge/WAF),
- Proveedores IA externos (si aplica).

## Template de evaluación por vendor

- servicio provisto,
- datos procesados,
- criticidad para negocio,
- controles de seguridad declarados,
- incident history,
- riesgo residual,
- plan de mitigación.

## Cadencia

- reassessment anual,
- reassessment inmediato tras incidente mayor/cambio de alcance.

## Criterios de salida

- incumplimiento sostenido de seguridad/compliance,
- riesgo residual no aceptable por negocio.
