# Crisis Communication Plan

Stakeholders: clientes, empleados, reguladores, media, partners.

## Plantilla holding statement

"Estamos investigando un incidente de seguridad. Activamos nuestro plan de respuesta y compartiremos actualizaciones verificadas."

## Reglas

- portavoz designado único.
- mensajes por severidad y audiencia.
- cadencia fija de updates.
