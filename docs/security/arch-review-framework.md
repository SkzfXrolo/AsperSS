# Security Architecture Review Framework

Cuándo aplicar: feature nueva, refactor mayor, cambio de vendor.

Método: STRIDE sobre diagrama de arquitectura y flujos de datos.

Checklist:

- trust boundaries
- authn/authz
- cifrado en tránsito y reposo
- logging/auditoría
- dependencias externas

Salida: documento con riesgos, severidad, mitigaciones y fecha target.
