# Trust Score Design (0-100)

Inputs sugeridos:

- edad de cuenta
- consistencia geográfica de logins
- frecuencia de scans
- tasa de acuerdo con Oracle
- historial de baneos

Use cases:

- gating de acciones sensibles
- priorización de revisión antifraude

Privacidad:

- minimización de datos
- explicación del score al usuario
- retención limitada y revisable
