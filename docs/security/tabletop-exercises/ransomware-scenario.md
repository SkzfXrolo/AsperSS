# Tabletop: Ransomware Scenario (90 min)

## Setup

- participantes: IC, Tech lead, Legal/Comms, Ops.
- objetivo: validar contención y continuidad.

## Inject timeline

- T+0: alerta de cifrado masivo en hosts críticos.
- T+20: actor exige rescate.
- T+45: caída parcial de servicios.
- T+70: prensa contacta soporte.

## Decisiones esperadas

- aislamiento inmediato,
- preservación de evidencia,
- activación de comunicación oficial,
- restauración desde backups limpios.

## Lessons learned template

- qué funcionó,
- qué falló,
- acciones correctivas (owner + fecha).
