- Security
- Availability

- Confidentiality
- Privacy

## Estado inicial Argus

- Security: parcial
- Availability: parcial

## Plan de preparación

1. definir owners por control,
2. evidencias automatizadas (CI logs, access logs, change mgmt),
3. políticas formales (security, incident response, retention, vendor risk),
4. run de auditoría interna trimestral.

- **Vanta:** rápido onboarding, costo medio/alto.
- **Drata:** fuerte automatización.
- **Secureframe:** UX simple para equipos pequeños.
- **Tugboat:** alternativa con foco técnico.
