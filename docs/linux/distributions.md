# Distribuciones Linux: comparativa packaging

| Formato | Ventaja | Desventaja |
| --- | --- | --- |
| Snap | Auto-update simple | Startup mas lento |
| Flatpak | Sandbox fuerte | Integracion server limitada |
| AppImage | Portabilidad alta | Sin updates nativos |
| AUR | Nativo Arch | Mantenimiento comunitario |
