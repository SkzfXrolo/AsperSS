# Referencia de comandos CLI

| Comando | Flags clave | Descripcion |
| --- | --- | --- |
| `argus scan` | `--path`, `--format` | Ejecuta análisis local |
| `argus oracle-eval` | `--input`, `--model` | Evalúa señales con Oracle |
| `argus plugin-deploy` | `--jar`, `--server` | Publica plugin en server objetivo |
| `argus doctor` | `--verbose` | Diagnóstico del entorno |
