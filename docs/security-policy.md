# Security Policy

## Reporte de vulnerabilidades

Si detectas una vulnerabilidad, reportala de forma privada.

- Canal: `REVIEW: definir email/canal oficial`
- Incluir pasos de reproduccion y version afectada.

## Politica de disclosure

1. Confirmacion inicial dentro de 72 horas.
2. Analisis tecnico y severidad.
3. Fix y release coordinado.
4. Disclosure publico cuando el fix este disponible.
