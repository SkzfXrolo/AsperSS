# Best practices v2

Checklist extendido (extracto):

1. Aserciones enfocadas en comportamiento.
2. Evitar sleeps fijos.
3. Aislar IO externo.
4. Semillas determinísticas.
5. Naming explícito.
6. Mantener fixtures pequeñas y reutilizables.
7. Evitar mocks de detalles internos.
8. Priorizar pruebas de regresión de bugs reales.
9. Validar mensajes de error útiles.
10. Medir costo de ejecución.
