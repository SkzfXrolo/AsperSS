# Objections Handbook

1. "Es caro" -> ROI por reducción de fraude/staff load.  
2. "Ya usamos X" -> coexistencia + rollout por fases.  
3. "Falsos positivos" -> observer mode y tuning.  
4. "Integración compleja" -> onboarding guiado.  
5. "No confío en ML" -> híbrido reglas + ML explicable.  
6. "Soporte insuficiente" -> SLA por tier.  
7. "Vendor lock-in" -> export de datos/API.  
8. "Privacidad" -> políticas y DPA.  
9. "Latencia" -> arquitectura optimizada.  
10. "No hay casos reales" -> template case studies.  
11. "No tengo equipo" -> servicios de implementación.  
12. "Compliance" -> roadmap + controles.  
13. "Escala" -> K8s/GitOps disponibles.  
14. "Riesgo reputacional" -> comunicación y status page.  
15. "Tiempo de adopción" -> quickstart + playbooks.
