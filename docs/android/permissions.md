# Permisos Android y privacidad

Este documento describe el contenido recomendado para la pantalla de privacidad y permisos de la app Android de Argus.

## Permisos esperados

- Internet: enviar/recibir datos de estado anti-cheat.
- Network state: detectar conectividad para reintentos seguros.
- Notifications (si aplica): informar eventos importantes al usuario.

## Texto sugerido para pantalla de privacidad

"Argus Android solicita solo permisos necesarios para operar de forma segura y mostrar informacion de estado. No recolecta contenido personal fuera del alcance tecnico de anti-cheat y diagnostico."

## Buenas practicas

1. Explicar cada permiso en lenguaje claro.
2. Incluir enlace a politica de privacidad completa.
3. Permitir continuar con funciones limitadas si un permiso no critico es denegado.
4. Registrar consentimiento donde aplique.
