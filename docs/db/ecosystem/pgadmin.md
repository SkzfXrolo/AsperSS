# pgAdmin (Pack 48-H Round 5 · #148)

## Rol

GUI oficial PostgreSQL: exploración schema, query tool, backups ligeros.

## Pros

- Gratis, multiplataforma.
- Explain visual.

## Contras

- Pesado; no ideal en prod con datos sensibles en laptops no endurecidos.

## Argus

Uso staging + VPN; nunca credenciales prod en máquinas personales sin MDM.
