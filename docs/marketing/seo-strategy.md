# SEO Strategy

## Keywords objetivo
- anti-cheat minecraft
- security scanner windows
- threat detection ai

## On-page
- Títulos únicos por página.
- H1/H2 jerárquicos.
- Enlazado interno entre docs y páginas de producto.

## Off-page
- Guest posts en comunidades seguridad/gaming.
- Presencia activa en Discord/Reddit/foros técnicos.
- Backlinks desde partners.

## SEO técnico
- `robots.txt` claro.
- `sitemap.xml` actualizado por script.
- Schema.org para producto, FAQ y artículos.
