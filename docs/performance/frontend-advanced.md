# Frontend Performance Advanced (Pack48-G)

## Code splitting

- Route-based para secciones grandes.
- Component-based para widgets pesados.

## Build optimization

- Tree shaking (Vite/Rollup).
- Minificación y chunking controlado.

## CSS strategy

- Critical CSS inline.
- Resto async/deferred.

## Resource hints

- Preconnect a orígenes críticos.
- Preload de fuentes y CSS clave.

## Service Worker patterns

- Cache-first para estáticos.
- Network-first para datos frescos.
- Offline fallback básico para panel.

## Web Push

- Re-engagement y notificaciones de eventos críticos sin polling agresivo.
