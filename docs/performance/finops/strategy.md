# FinOps Strategy

Principios:
- **Visibilidad:** costo por servicio, tenant y feature.
- **Optimización:** reducir desperdicio, right-sizing continuo.
- **Operación:** decisiones costo/rendimiento dentro del ciclo de entrega.

Ritmo recomendado:
- revisión semanal de anomalías,
- revisión mensual de optimizaciones,
- planificación trimestral de capacidad/costo.
