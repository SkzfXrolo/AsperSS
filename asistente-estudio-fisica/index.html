Ejercicio 1 — Fuerza neta (dibujando)

Idea: varias fuerzas tiran a la vez. La fuerza neta es “todas juntas, ¿hacia dónde y con cuánta fuerza?”.
F fuerza (Newtons) Fneta suma de todas → derecha / ← izquierda

Caso A — misma línea

  1. Elegí sentido +: derecha = +, izquierda = −
  2. Escribí: +150 − 400 − 200
  3. Resultado: −450 → el menos significa izquierda
  4. En el dibujo: flechas a escala y medí el resultante
Calculadora / Google
150 - 400 - 200
✅ A: 450 N horizontal a la izquierda

Caso B — una ↑ y una →

  1. Dibujá 70 N a la derecha y 90 N arriba (forman una L)
  2. La diagonal es Fneta (método del paralelogramo)
  3. Módulo con Pitágoras: √(90² + 70²)
  4. Ángulo con la horizontal: arctan(90/70)
F = √(90² + 70²) = √13000 ≈ 114 N
θ = arctan(90/70) ≈ 52°
Google (importante)
sqrt(90*90 + 70*70) → 114
arctan(90/70) in degrees → 52,1°

Si te da ~3: apretaste tan en vez de tan⁻¹ / arctan.

✅ B: ≈ 114 N a ≈ 52° sobre la horizontal (arriba-derecha)

Ejercicio 2 — Justificar con cuentas

Idea: es el mismo ejercicio 1, pero en vez de medir el dibujo, usás fórmulas. Los números tienen que coincidir.
ΣFx suma en horizontal ΣFy suma en vertical θ ángulo
  1. Caso A: ΣFx = 150 − 400 − 200 = −450 N → 450 N ←
  2. Caso B: ΣFx = 70 · ΣFy = 90
  3. F = √(ΣFx² + ΣFy²) = 114 N
  4. θ = arctan(ΣFy/ΣFx) = 52,1° (reportá 3 cifras significativas)
A: ΣFx = 150 − 400 − 200 = −450 N
B: F = √(70²+90²) = 114 N · θ = arctan(90/70) = 52,1°
✅ Mismos resultados que el Ej. 1. Eso justifica el método gráfico.

Ejercicio 3 — Carrito en la rampa

Idea: plano liso = sin fricción. Está quieto → ΣF = 0. El resorte cancela lo que lo tira abajo.

Datos: m=2,00 kg · θ=20° · N=18,8 N · k=120 N/m

m masa g 9,8 m/s² θ ángulo 20° N normal Fe resorte k dureza Δx estiramiento
  1. Peso: P = m·g = 2×9,8 = 19,6 N ↓ (siempre vertical)
  2. Se parte en 2: ∥ = mg senθ (quiere bajar) · ⊥ = mg cosθ (aprieta)
  3. Paralela: 19,6×sen20° ≈ 6,70 N
  4. Normal: dato del enunciado = 18,8 N ⊥ al plano
  5. Resorte: como está quieto → Fe = 6,70 N hacia arriba de la rampa
  6. Estiramiento: Δx = Fe/k = 6,70/120 = 5,58 cm
Calculadora
2 * 9.8 → 19,6
2 * 9.8 * sin(20) → 6,70
6.70 / 120 → 0,0558 m (= 5,58 cm)
✅ P=19,6 N · N=18,8 N · Fe=6,70 N · Δx=5,58 cm

Frase mágica: liso + quieto ⇒ Fe = mg senθ

  2. 0→12 s: sube de 5 a 20 → acelera · a=(20−5)/12=1,25
  3. 12→24 s: chato en 20 → MRU · a=0

Ejercicio 5 — Pelota desde la azotea

Idea: tirás arriba desde 25 m. Sube, se frena, cae, pasa la azotea y pega en el piso. Gravedad siempre tira abajo.

H=25 m · v₀=36 km/h ↑ · g=9,8 · sin aire

y₀ altura inicial 25 m v₀ vel. inicial a −9,8 m/s² t tiempo y=0 suelo
  1. Convertí: 36÷3,6 = 10 m/s
  2. Signos: arriba=+ · y₀=25 · v₀=+10 · a=−9,8 · suelo y=0
  3. Fórmula: y = y₀ + v₀t + ½at² → 0 = 25 + 10t − 4,9t²
  4. Cuadrática: 4,9t² − 10t − 25 = 0 → t ≈ 3,50 s (descartá el negativo)
  5. Impacto: v = 10 − 9,8×3,50 = −24,3 m/s → 24,3 m/s ↓
Google
36 / 3.6 → 10
(10 + sqrt(590)) / 9.8 → 3,50
10 - 9.8 * 3.50 → −24,3
sqrt(590) → 24,3 (atajo)
✅ Tiempo total ≈ 3,50 s · Impacto 24,3 m/s hacia abajo
