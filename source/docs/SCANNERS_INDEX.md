# SCANNERS INDEX

- `registry_anomalies`: detecta claves de persistencia/anomalas en registry.
- `dns_artifacts`: revisa cache DNS, hosts y overrides.
- `browser_history`: extrae historial reciente de navegadores.
- `credential_stores`: revisa LSA/Vault artifacts.
- `wmi_subscriptions`: enumera persistencia WMI subscription.
- `com_objects`: detecta COM hijacking candidates.
- `scheduled_task_xml`: parsea XML de tareas con heuristicas.
- `print_drivers`: detecta anomalias tipo PrintNightmare.
- `dll_search_order`: detecta DLL search order hijacking.
- `firewall_rules`: detecta reglas firewall demasiado permisivas.
