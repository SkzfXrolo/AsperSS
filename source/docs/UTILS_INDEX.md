# UTILS INDEX

- `pe_parser`: parser PE basico (secciones/imports/entropia).
- `entropy`: calcula entropia Shannon.
- `string_extract`: extrae strings ANSI/Unicode.
- `hash_utils`: helpers de hashing e imphash placeholder.
- `sigcheck`: wrapper de firma digital Authenticode.
- `sysmon_parser`: lectura/parsing simple de Sysmon.
